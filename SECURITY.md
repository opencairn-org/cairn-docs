# Security policy

This repository is the Cairn documentation site: static pages built with
Docusaurus. It runs no server code of its own.

## Reporting a vulnerability

Do not open a public issue. Email `security@johanneskueber.com` with "security"
in the subject. Reports are acknowledged within 7 days.

Vulnerabilities in Cairn itself belong to
[cairn-core](https://github.com/opencairn-org/cairn-core) or the provider
repositories; the same address reaches the maintainers.

## Supported versions

Only the published site (the `main` branch and the latest `v*` tag) is
maintained.
