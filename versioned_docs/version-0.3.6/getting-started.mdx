# Getting started

The fastest way to see Cairn running locally.

## Prerequisites

- Docker + Docker Compose
- (For development) Go 1.27, Node 24 and, for the Garmin worker,
  [uv](https://docs.astral.sh/uv/)

## Run the stack

Cairn's infrastructure (Postgres + TimescaleDB + PostGIS, NATS, an S3-compatible
store such as MinIO, and a mail catcher) runs in Docker; the core binary serves
the API and the embedded web UI.

```bash
# in cairn-core
cp dev.env.example dev.env   # once; tweak ports and secrets if needed
make dev-up        # postgres + nats + minio + mailpit
make dev-server    # core API on :8080 (rebuilds on save)
make dev-web       # SvelteKit dev server (HMR) on :5173
```

`dev.env` holds every variable the dev stack needs, including the bootstrap
admin (`CAIRN_INSTANCE_BOOTSTRAP_ADMIN_EMAIL` / `..._PASSWORD`). Open the web
UI on `:5173` and sign in with that account.

## Add a provider worker

Provider workers live in their own repos and connect to the same NATS. Run the
one(s) you need against the dev stack:

```bash
# Strava (Go) — in cairn-provider-strava
export CAIRN_NATS_URL=nats://localhost:4222
export CAIRN_WORKER_NAME=strava-fetcher
export CAIRN_WORKER_ENROLLMENT_TOKEN=...   # only with NATS auth-callout; from POST /api/admin/worker-enrollments
go run ./cmd/worker-strava

# Garmin (Python) — in cairn-provider-garmin
uv sync --locked
export CAIRN_NATS_URL=nats://localhost:4222
export CAIRN_WORKER_ENROLLMENT_TOKEN=...   # only with NATS auth-callout; from POST /api/admin/worker-enrollments
export CAIRN_GARMIN_EMAIL=you@example.com   # dev fallback; production delivers per-user credentials over NATS
export CAIRN_GARMIN_PASSWORD=...
uv run python -m cairn_garmin.main
```

:::tip
A worker's only contract with core is the **proto messages + the NATS
subjects** — there is no shared code dependency. See
[Provider workers](/architecture/workers).
:::
